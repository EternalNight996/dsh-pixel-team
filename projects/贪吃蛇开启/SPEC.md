# 贪吃蛇开启 — 需求与验收（t1）

## 1. 目标
交付一个可直接在浏览器打开就能玩的贪吃蛇小游戏（静态文件，无外部依赖）。

## 2. 功能需求
1. 20×20 网格，CELL=16，画布 320×320；初始蛇长 3，向右移动，每 120ms 走一格。
2. 食物随机生成且不与蛇身重叠；吃到 +10 分、蛇身 +1。
3. 方向键 / WASD 控制；不允许 180° 立即掉头（同 tick 双转向也不能瞬死）。
4. 空格或按钮暂停/恢复；按钮重开（分数归零、蛇重置）。
5. 撞墙或撞自身 → 游戏结束，显示「游戏结束 · 得分 N」。
6. 授权校验：本地 License 校验（演示 key），未授权时禁止开始，授权后显示已授权。
7. 卸载/关闭时清理计时器与键盘监听。

## 3. 非目标（明确不做）
- 不做联机/排行榜/账号/持久化存档/多关卡/皮肤/音效。
- 不引入第三方依赖，不修改平台插件代码。
- 产物只写 `projects/贪吃蛇开启/`。

## 4. 产物
- `projects/贪吃蛇开启/index.html`：页面与样式。
- `projects/贪吃蛇开启/game.mjs`：纯逻辑（可被 Node 测试导入）。
- `projects/贪吃蛇开启/smoke.mjs`：冒烟测试（移动/食物/碰撞/授权）。

## 5. 验收标准（可测试）
- 验收标准可测试：本文件第 5 节给出可执行断言，smoke.mjs 覆盖。
- 开放问题已关闭或明确延期：无开放问题；License 校验采用本地演示 key（真实授权系统不在本次范围内）。
