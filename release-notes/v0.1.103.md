# dsh-pixel-team 0.1.103

Released 2026-10-31. GitHub-only release; npm `latest` stays on 0.1.16.

## Changed

- Founding state is isolated per conversation; old requests cannot update a newly
  selected session.
- Conversation card shows goal, active/pending task with member art/role/error,
  and completed results in a collapsed section.
- Activity tasks expose `output` for folded results.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.103
# restart DSH once
```
