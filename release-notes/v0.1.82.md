# dsh-pixel-team 0.1.82

Released 2026-10-31. GitHub-only release; npm `latest` stays on 0.1.16.

## Fixed

- **Discard orphan staged plan**: if the captain session is detached, discarding
  a staged plan archives the team directly instead of failing with
  "captain session is not attached".
- **Inline confirmations**: stop task, team cleanup, archive teams and plan
  regeneration now show inline confirm bubbles instead of `window.confirm`
  popups; review errors are inline notices.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.82
# restart DSH once
```
