# dsh-pixel-team 0.1.76

Released 2026-10-30. GitHub-only release; npm `latest` stays on 0.1.16.

## Added

- **Headless / 24h deployment kit**
  - `scripts/headless-healthcheck.mjs --workspace . --stale-min 20` reports active
    teams, open attempts and stale attempts (exit 1 on stale).
  - `scripts/install-dsh-supervisor.ps1` registers a per-user Windows task that
    restarts the DSH desktop process when it exits.
  - `docs/headless-deployment.md` covers Windows Task Scheduler and systemd.
- Healthcheck unit tests run in `pnpm verify`.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.76
# restart DSH once
```
