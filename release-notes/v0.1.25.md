# dsh-pixel-team 0.1.25

Released 2026-10-29. GitHub-only release; npm `latest` stays on 0.1.16.

## Changed

- The fixed clarification form is gone from the founding wizard. The model
  generates its own template-like interview from the task requirement and the
  selected mode: 3-6 questions, each with concrete options (single/multi) and a
  free-form "other answer" input.
- The answers are converted by the model into the clarification object (type,
  scale, UI, platforms, hardware, constraints, exclusions, acceptance, memory
  hints); unanswered questions use the mode's baseline.
- New host routes: POST /plugins/dsh-pixel-team/interview/questions and
  POST /plugins/dsh-pixel-team/interview/answers.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.25
# restart DSH once: host routes changed
```
