# dsh-pixel-team 0.1.24

Released 2026-10-29. GitHub-only release; npm `latest` stays on 0.1.16.

## Changed

- The 志向 step shows only one annotation line, 目标; the long hint and the
  character/shortcut meta line were removed.
- AI polish inserts the expanded requirement directly into the goal textarea.
  The preview panel, hidden-condition checkboxes and confirm button are gone, so
  the user simply edits the text (or keeps it) and decides whether to advance.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.24
# client-only change: refresh the page after install; no app restart needed
```
