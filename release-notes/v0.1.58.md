# dsh-pixel-team 0.1.58

Released 2026-10-29. GitHub-only release; npm `latest` stays on 0.1.16.

## Added

- **Actual token metering.** Each task records the session event seq when it
  enters `in_progress`; on a terminal transition the plugin folds
  `assistant/message.usage` (host-reported input/output tokens) and writes a
  `usage-actual` cost entry with the configured rates. A task with actual usage
  supersedes its provisional spawn estimate in 名册.
- Config:

```yaml
cost:
  usage: actual        # actual | estimate
  pricing:
    inputPer1k: 0.0005
    outputPer1k: 0.0015
```

Rules: missing usage falls back to estimate (members) or 未计量 (captain); rates
are user-configured (the host exposes tokens, not prices).

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.58
# restart DSH once: host code changed
```
