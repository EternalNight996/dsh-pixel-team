# dsh-pixel-team 0.1.11

Released 2026-10-27.

## Work-only delivery review

- Delivery now requires at least one completed `review` task with
  `verdict=pass`, even when the whole graph is ordinary work. A team with
  completed work and no passing review is blocked.
- `research`, `docs`, and `debate` quick-start reviews are now quality review
  tasks targeting their synthesis/draft work.
- `fullstack` without recognizable disjoint layers keeps its work DAG but still
  gets a quality review gate over the integration task.
- Captains can add `kind:review` + `reviewedTaskId` to a manual work-only plan
  when it has no review.

## Install

```bash
dsh plugin --profile desktop add dsh-pixel-team@0.1.11
# restart DSH
```
