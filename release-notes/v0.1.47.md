# dsh-pixel-team 0.1.47

Released 2026-10-29. GitHub-only release; npm `latest` stays on 0.1.16.

## Added

- **Quality gate configuration** via plugin config `quality`:

```yaml
quality:
  autoVerify: true    # host re-runs declared verify commands (default true)
  autoReview: true    # host auto-completes ready review tasks after all gates pass
  commands: ["git diff --check"]  # verify commands for generated projects
```

When `autoReview` is on, the host closes a ready review task itself only after
every gate is completed, the reviewed task's acceptance and host-run commands
all pass, no task failed, and the verdict is still bound to the artifact bytes.

## Fixed

- Generated-project plans no longer inherit the plugin's own `pnpm typecheck`.
  They default to `git diff --check` (or `quality.commands`), so quality gates
  audit the product workspace rather than the plugin source.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.47
# restart DSH once: host code changed
```
