# dsh-pixel-team 0.1.81

Released 2026-10-31. GitHub-only release; npm `latest` stays on 0.1.16.

## Fixed

- **Staged plan visibility**: if the current session has no team but the
  workspace has a staged plan, it is surfaced again; the plan editor uses the
  plan's captain session and the current session's model directory.
- **Crash containment**: the hall is wrapped in a React error boundary. A bad
  plan/renderer error shows a retry toast instead of killing DSH.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.81
# restart DSH once
```
