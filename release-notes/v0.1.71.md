# dsh-pixel-team 0.1.71

Released 2026-10-30. GitHub-only release; npm `latest` stays on 0.1.16.

## Added

- **Human delivery acceptance**: a team whose technical `delivery.ok` passed can
  be signed off from the team panel. The state stores `acceptedAt`/`acceptedBy`
  separately from the technical gate; the snapshot and UI show "已验收".

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.71
# restart DSH once
```
