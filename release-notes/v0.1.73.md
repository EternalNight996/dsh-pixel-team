# dsh-pixel-team 0.1.73

Released 2026-10-30. GitHub-only release; npm `latest` stays on 0.1.16.

## Added

- **Cross-model review** (`quality.crossModelReview`, default false): at plan
  approval, a review task whose reviewer uses the same provider/model as the
  implementation owner is rejected with a clear message. Existing content-bound
  verdicts already bind review evidence to artifact digests.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.73
# restart DSH once
```
