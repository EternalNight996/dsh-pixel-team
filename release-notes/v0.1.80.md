# dsh-pixel-team 0.1.80

Released 2026-10-30. GitHub-only release; npm `latest` stays on 0.1.16.

## Changed

- Mode row order: "超级快速执行" takes the first position (former 极速草稿 slot);
  "极速草稿（产量优先）" moves to the end.
- The memory "goldfish mode" hint is a fixed bottom-right notification toast,
  not an inline banner inside the sheet body.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.80
# restart DSH once
```
