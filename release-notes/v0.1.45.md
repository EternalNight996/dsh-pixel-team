# dsh-pixel-team 0.1.45

Released 2026-10-29. GitHub-only release; npm `latest` stays on 0.1.16.

## Fixed

- **0.1.44 failed to load** with "Cannot find module lib/architecture.js":
  the generated `lib/architecture.js` and `lib/types/architecture.d.ts` were not
  committed, so the GitHub tag shipped without them while `lib/members.js`
  imported the module. Both are tracked now.

Install 0.1.45 instead of 0.1.44.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.45
# restart DSH once: host code changed
```
