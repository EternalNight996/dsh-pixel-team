# dsh-pixel-team 0.1.90

Released 2026-10-31. GitHub-only release; npm `latest` stays on 0.1.16.

## Changed

- 志向 is the first step; 道统 follows.
- Super-fast skips interview/doctrine/sect to oath and uses the template plan
  instead of AI plan generation.
- Oath replaces an existing sect directly without a confirmation prompt.
- Solo sect is labeled 散修.
- Lost responses are reconciled against the staged team list before reporting
  failure.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.90
# restart DSH once
```
