# dsh-pixel-team 0.1.50

Released 2026-10-29. GitHub-only release; npm `latest` stays on 0.1.16.

## Added

- **Solo auto-continue**: for a zero-member team, once a task is completed the
  scheduler wakes the captain for the next ready task (deduped per task; the first
  task is announced at approval). No more manual "继续" after every task.
- **Release guard**: `pnpm verify:release-guard` fails when a generated `lib/`
  file is untracked or a relative import cannot be resolved, preventing the class
  of broken package shipped in 0.1.44.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.50
# restart DSH once: host code changed
```
