# dsh-pixel-team 0.1.48

Released 2026-10-29. GitHub-only release; npm `latest` stays on 0.1.16.

## Changed

- All quality options are individually optional config fields with defaults:

```yaml
quality:
  autoVerify: true          # host re-runs verify commands
  autoReview: false         # host completes ready review tasks after the audit
  requireAcceptance: true   # auto review needs every acceptance item to pass
  commands: ["git diff --check"]
  commandsByProject:        # per product root
    "projects/贪吃蛇": ["node projects/贪吃蛇/smoke.mjs"]
  verifyTimeoutMs: 120000
```

- Auto review performs the same evidence checks a human reviewer does: all gates
  completed, no failed task, acceptance passed (configurable), host commands
  passed, and the verdict bound to the reviewed artifact bytes. It is not a
  rubber stamp and cannot skip a failing gate.

## Install (GitHub)

dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.48
