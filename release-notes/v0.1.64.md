# dsh-pixel-team 0.1.64

Released 2026-10-30. GitHub-only release; npm `latest` stays on 0.1.16.

## Changed

- **Archive without reload**: archived teams are filtered out of the roster
  locally; the current selection falls back instead of reloading the page.
- **Accurate cost rates**: `cost.pricing` now accepts per-model overrides and
  cache-read/cache-write rates. The session model selects its rate table, and
  cache tokens are billed separately from uncached input.

```yaml
cost:
  usage: actual
  pricing:
    inputPer1k: 0.0005
    outputPer1k: 0.0015
    cacheReadPer1k: 0.00005
    models:
      deepseek-flash:
        inputPer1k: 0.0005
        outputPer1k: 0.0015
```

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.64
# restart DSH once: host code changed
```
