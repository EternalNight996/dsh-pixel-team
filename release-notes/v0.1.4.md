# dsh-pixel-team 0.1.4

Released 2026-10-27.

## Delivery verification

- **The host now actually runs declared verification commands** when a quality
  task completes. A real non-zero exit (or timeout) rejects the completion;
  member-reported `commandsRun` no longer count as a pass. Evidence is stored
  with the host exit code and output.
- The check runs only after the status transition and contract are legal, so a
  claimed task cannot execute commands on the way to an illegal direct
  completion.
- Verification process trees are terminated on timeout (Windows `taskkill /T`),
  preventing orphaned test processes and locked workspaces.

## Full-stack quality

- The fullstack quick-start template now emits a quality DAG when the workspace
  has two genuinely disjoint frontend/backend roots (for example `web/` +
  `server/`, `apps/web/` + `apps/api/`):
  requirements → implementation (frontend/backend) → integration → verification
  → review.
- Without recognizable disjoint layers the template stays ordinary work rather
  than inventing a scope that would dead-lock honest changes.

## Install

```bash
dsh plugin --profile desktop add dsh-pixel-team@0.1.4
# restart DSH
```
