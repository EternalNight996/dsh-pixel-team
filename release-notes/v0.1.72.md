# dsh-pixel-team 0.1.72

Released 2026-10-30. GitHub-only release; npm `latest` stays on 0.1.16.

## Added

- Delivery acceptance records the digests of the reviewed artifacts. A later
  change makes the snapshot report `acceptanceStale`; the panel shows
  "交付后产物已变化，验收失效" instead of a silently valid acceptance.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.72
# restart DSH once
```
