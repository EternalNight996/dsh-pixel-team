# dsh-pixel-team 0.1.8

Released 2026-10-27.

## Abandoned-team cleanup

- New captain tool `agent_teams_cleanup`: archives teams in the workspace whose
  tasks are all completed/cancelled/failed and whose newest activity is older
  than `older_than_days` (default 7, max 3650).
- The current captain's team is never a candidate.
- Dry-run by default; pass `dry_run=false` to archive the reported candidates.
- Candidate selection is a pure helper, so the dry run and the real pass agree.

## Install

```bash
dsh plugin --profile desktop add dsh-pixel-team@0.1.8
# restart DSH
```
