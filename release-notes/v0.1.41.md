# dsh-pixel-team 0.1.41

Released 2026-10-29. GitHub-only release; npm `latest` stays on 0.1.16.

## Plan relevance

- A failed AI plan generation records its reason; the plan review shows it on the
  alignment card instead of silently presenting template tasks.
- Template fallback tasks now embed the goal, mode, platforms, interview
  constraints, acceptance, excluded boundaries and product root.
- AI plans are relevance-checked against goal + interview constraints.

## UI

- 功德碑 cultivation is settled by the hall overlay too, so a captain executing
  tasks alone gains progress even with the activity panel closed.
- 名册 history is a dropdown (more space).
- 藏经阁 task details show PASS/FAIL/pending per acceptance criterion again.
- 名册 has a cost ledger: today's spend, per-task totals, recent entries; spawn
  cost log entries now include the task id.
