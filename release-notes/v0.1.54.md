# dsh-pixel-team 0.1.54

Released 2026-10-29. GitHub-only release; npm `latest` stays on 0.1.16.

## Changed

- AI plan generation can now declare `coverageOf` per task (exact interview
  requirement strings). The plan prompt requests it; parsing carries it into the
  staged tasks; the library's requirement table uses it for per-item PASS/FAIL.
  Items not covered by the model still receive deterministic distribution.
- Regression test for parsing AI coverage and carrying it into the plan.

Note: true browser E2E smoke passed against v0.1.53 (hall renders, version badge,
宗门志 sheet); a full create→approve→execute browser flow is still not automated.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.54
# restart DSH once: host code changed
```
