# dsh-pixel-team 0.1.78

Released 2026-10-30. GitHub-only release; npm `latest` stays on 0.1.16.

## Fixed

- **Renderer crash rollback**: 0.1.77's staged-plan/session fallback is removed;
  WorkspaceActivity returns to the 0.1.76 layout. 0.1.76 remains the last known
  good baseline.
- **Interview**:
  - single-select options can be deselected;
  - custom answers can be added with the + button and removed as chips;
  - switching conversations preserves the questions, answers and current step
    per session instead of regenerating them.
- **Wizard layout**: footer pinned to the bottom; AI polish moved above the mode
  row; "超级快速执行" skips the AI interview.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.78
# restart DSH once
```
