# dsh-pixel-team 0.1.105

Released 2026-10-31. GitHub-only release; npm `latest` stays on 0.1.16.

## Added

- Resume-last increments a durable per-task retry counter, caps at 3 (needs human
  triage), and rolls the counter back when dispatch fails.
- Halted teams remain on the separate explicit resume path.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.105
# restart DSH once
```
