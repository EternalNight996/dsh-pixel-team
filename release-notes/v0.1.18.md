# dsh-pixel-team 0.1.18

Released 2026-10-29. GitHub-only release; npm `latest` stays on 0.1.16.

## Added

- The hall header shows the running plugin version (`v0.1.18`), so a stale
  install is visible at a glance. The 道通藏书阁 header shows it too.

## Install (GitHub)

```bash
# from the GitHub tag (recommended for this GitHub-only line)
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.18
# restart DSH
```
