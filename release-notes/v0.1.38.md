# dsh-pixel-team 0.1.38

Released 2026-10-29. GitHub-only release; npm `latest` stays on 0.1.16.

## Added

- The plan review now has a **需求对齐** card: goal, mode, platforms, interview
  constraints, product root, and the plan source. A template fallback is flagged
  in amber so the user can return to chat and revise instead of approving
  unrelated tasks.
- `planSource` / `planProjectRoot` are persisted on the staged team and included
  in the activity snapshot.

## Fixed

- **Solo plans can be approved**: with zero members the approve button is enabled
  when all tasks belong to the captain; the review copy now says 掌门单干 /
  唤醒掌门 / 0 名修士（掌门执行）.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.38
# restart DSH once: host code changed
```
