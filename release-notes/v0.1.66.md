# dsh-pixel-team 0.1.66

Released 2026-10-30. GitHub-only release; npm `latest` stays on 0.1.16.

## Fixed

- **Roster archive did nothing when the list was already archived.** The roster
  history reads `.agent-teams/archive`, but the cleanup route only scanned active
  team directories. The route now accepts `include_archived` and moves matching
  archived teams to `archive/.retired` (excluded from history), so the dropdown
  actually clears. Files are retained for recovery.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.66
# restart DSH once: host code changed
```
