# dsh-pixel-team 0.1.19

Released 2026-10-29. GitHub-only release; npm `latest` stays on 0.1.16.

## Changed

- Opening the running 藏经阁 now shows the live 道通藏书阁 projection — swimlanes,
  dependency edges, acceptance results, blocker bar and today's cost — instead of
  the static member/contract panel.
- A staged plan still opens the plan editor in that sheet, so approval, discard
  and revise keep working.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.19
# restart DSH
```
