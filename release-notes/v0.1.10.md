# dsh-pixel-team 0.1.10

Released 2026-10-27.

## Hardening and build quality

- `hardening` quick-start now emits a quality DAG:
  requirements (audit) → implementation (fix) → verification → review.
- `build` quick-start now emits:
  implementation → verification → integration (release) → review, with a
  dedicated reviewer role.
- Both carry objective/acceptance; implementation/release contracts receive
  workspace-derived inScope/verify.

## Install

```bash
dsh plugin --profile desktop add dsh-pixel-team@0.1.10
# restart DSH
```
