# dsh-pixel-team 0.1.89

Released 2026-10-31. GitHub-only release; npm `latest` stays on 0.1.16.

## Fixed

- Solo mode skips the sect step (four-step wizard), still creates a captain-only
  plan.
- The generation-lost fallback no longer competes with the live request; only
  orphaned submissions (remount) recover, with a 180s window.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.89
# restart DSH once
```
