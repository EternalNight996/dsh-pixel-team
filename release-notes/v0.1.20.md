# dsh-pixel-team 0.1.20

Released 2026-10-29. GitHub-only release; npm `latest` stays on 0.1.16.

## Changed

- The hall banner now probes the configured memory endpoint before prompting.
  - Reachable brain: 「已连接大脑」 with a green dot.
  - Unreachable: the memory-eternal install hint.
  - Probe is cached for 60s; exit code / auth failures count as missing.
- New host route: GET /plugins/dsh-pixel-team/memory/status → { connected }.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.20
# restart DSH
```
