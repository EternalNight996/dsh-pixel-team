# dsh-pixel-team 0.1.27

Released 2026-10-29. GitHub-only release; npm `latest` stays on 0.1.16.

## Changed

- With an unfinished sect, clicking 立誓开宗 now shows a confirmation bubble above
  the submit button: "当前宗门尚未结束：继续将结束旧宗门并立即开新宗，是否确认？"
  with 取消 / 结束并开新宗. Nothing is sent or deleted until the user confirms.
- The same bubble appears if the server reports the existing-team condition.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.27
# client-only change: refresh the page after install, no app restart needed
```
