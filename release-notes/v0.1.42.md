# dsh-pixel-team 0.1.42

Released 2026-10-29. GitHub-only release; npm `latest` stays on 0.1.16.

## 名册

- The history dropdown is the header and every option shows that team's spend.
- Details follow the selection; the cost ledger is at the bottom (per-task totals
  and recent entries for the selected team). The today total was removed.
- The cost report route takes `teamId`, so the ledger switches with the dropdown.

## 藏经阁

- Numbered interview requirement checklist with PASS/FAIL state.
- Numbered project skeleton: each task shows failure count and its own spend;
  expanding a task shows description/dependencies/PASS-per-criterion.
- Only per-task cost here — full billing detail stays in 名册.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.42
# restart DSH once: host code changed
```
