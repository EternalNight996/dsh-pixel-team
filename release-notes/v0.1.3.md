# dsh-pixel-team 0.1.3

Released 2026-10-27.

## Delivery fixes

- **Quick-start fix / feat / array now generate a quality DAG by default**:
  - fix: implementation → verification → review
  - feat: requirements → implementation → verification → review
  - array: requirements → implementation → verification → review
  Each task carries objective / acceptance / inScope / verify; `inScope` and the
  verification command are derived from the actual workspace instead of hardcoded
  `src/` / `pnpm test`.
- **Work tasks must now have a non-empty output** before they can complete or be
  counted as delivered. A one-line empty completion no longer produces
  `delivery.ok=true`.
- **Artwork fix**: the app icon is embedded separately from the 24 cultivation
  portraits, keeping the packaged artwork contract intact.

## Install

```bash
dsh plugin --profile desktop add dsh-pixel-team@0.1.3
# restart DSH
```
