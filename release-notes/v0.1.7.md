# dsh-pixel-team 0.1.7

Released 2026-10-27.

## Delivery report

- When `canDeclareDelivery` is clean, `agent_teams_status` writes
  `.agent-teams/<team-id>/delivery-report.md` and returns its path.
- The report records the goal, quality/work tasks, acceptance evidence,
  changed paths, host-verified commands, review verdicts, open findings,
  attempts, duration and residual-risk warnings.
- The file lives with the team state, so archiving/shutdown carries it along.

## Install

```bash
dsh plugin --profile desktop add dsh-pixel-team@0.1.7
# restart DSH
```
