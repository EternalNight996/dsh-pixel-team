# dsh-pixel-team 0.1.21

Released 2026-10-29. GitHub-only release; npm `latest` stays on 0.1.16.

## Added

- Clarification options are AI-generated for the actual requirement instead of a
  fixed menu. The host proposes per-section candidates — type/scale, UI
  references and styles, platforms, hardware models, constraints, exclusions,
  executable acceptance assertions and memory hints — through
  POST /plugins/dsh-pixel-team/clarify/options. Each list stays editable, and the
  static menu only appears when the model route is unavailable.

## Changed

- 开山立业 (feat) is now the first doctrine template and the default selection
  in the founding wizard, with the planner/implementer/verifier/reviewer roster.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.21
# restart DSH once: this release adds host code (clarify/options route)
```
