# dsh-pixel-team 0.1.6

Released 2026-10-27.

## Delivery evidence

- `agent_teams_status` now reports machine-readable delivery counters:
  - quality tasks completed / total
  - review rounds
  - host-verified commands
  - attempts
  - total completed-task duration
  - work tasks completed / total
- A completed quality task with declared verify commands but no
  `[host-verified]` evidence is called out explicitly instead of passing
  silently.
- The status render includes a compact `Delivery evidence` line, so a captain
  can see whether a delivery is verified or only self-reported.

## Install

```bash
dsh plugin --profile desktop add dsh-pixel-team@0.1.6
# restart DSH
```
