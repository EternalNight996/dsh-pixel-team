# dsh-pixel-team 0.1.75

Released 2026-10-30. GitHub-only release; npm `latest` stays on 0.1.16.

## Added

- **Read-only native Agent Team bridge**: when the host's experimental
  `agentTeam` projection exists for the same captain, the plan review shows its
  member/task counts and completion. The plugin never mutates native state.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.75
# restart DSH once
```
