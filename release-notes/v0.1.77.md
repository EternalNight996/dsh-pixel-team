# dsh-pixel-team 0.1.77

Released 2026-10-30. GitHub-only release; npm `latest` stays on 0.1.16.

## Changed

- **Solo first**: the single-captain choice is on the doctrine step; solo hides
  sect/role configuration entirely, so only goal + acceptance remain.
- **Super fast**: a vow-step option that skips the AI interview and goes to
  sect/oath. AI polish is hidden outside developer mode; enable it with
  `localStorage.setItem('dsh-pixel-team.dev', '1')`.
- **Staged-plan fallback**: a plan created before a session switch/restart now
  appears in the hall for review instead of an empty sect.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.77
# restart DSH once
```
