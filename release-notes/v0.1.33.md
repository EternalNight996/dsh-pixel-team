# dsh-pixel-team 0.1.33

Released 2026-10-29. GitHub-only release; npm `latest` stays on 0.1.16.

## Removed

- The 贪吃蛇大作战 panel is gone from the plugin. It was **task output** from a
  founding run (a game built by the team), not platform code, and should never
  have been wired into the hall.

## Changed

- Plan generation now enforces the product boundary: task products are written
  under `projects/<short-name>/`; the plugin's `src/`, `lib/`, `scripts/`,
  `package.json` and `tsconfig` may only be touched when the goal explicitly
  asks to change the plugin itself.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.33
# restart DSH once: host bundle changed
```
