# dsh-pixel-team 0.1.57

Released 2026-10-29. GitHub-only release; npm `latest` stays on 0.1.16.

## Fixed

- **Empty/zero cost ledger**: the report only read the current session workspace.
  Real spend can live beside the DSH profile, so a team with costs showed no
  data. The report now merges session workspace + `DSH_PROFILE_DIR` + `DSH_HOME`
  logs, dedupes entries and sums today from the merged log.
- Spawn cost entries attach the member's pending task when no attempt has been
  claimed yet, improving per-task attribution for new runs.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.57
# restart DSH once: host code changed
```
