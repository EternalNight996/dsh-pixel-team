# dsh-pixel-team 0.1.23

Released 2026-10-29. GitHub-only release; npm `latest` stays on 0.1.16.

Phase B of the multi-mode refactor completes modules 3/4/5.

## Added

- **Library panel**: the 道通藏书阁 header shows the development mode as a
  colored badge plus the whole-DAG acceptance gate totals.
- **Mode budgets**: draft/monetize $15/day, precision/legacy/compliance $50/day,
  per-task budget follows the mode; the profile cost config overrides. Cost log
  entries carry the mode.
- **Dead-loop gate**: repeated retries of the same failed task reach the mode
  threshold and prompt 介入人工排查 / 继续执行; intervene keeps the failure for
  manual triage.
- **Verifier strategies**:
  - draft / monetize: smoke only, 2 failures stop;
  - precision: unit/network suite, 3 failures reported;
  - legacy: discovered old regression command runs first and blocks on failure;
  - compliance: dependency inventory + plaintext password/token scan.
  The verification task states the mode strategy; the generated script prints
  【PASS】/【FAIL】 and writes its log beside itself.
