# dsh-pixel-team 0.1.30

Released 2026-10-29. GitHub-only release; npm `latest` stays on 0.1.16.

## Added

- **Solo captain mode**: in the 宗门 step, tick 单掌门模式（不派修士，节省资源）.
  The staged plan then has no members and every task is assigned to the captain,
  who executes them in chat — zero member resources.
- **Mode direction labels** so the choice is explicit: 极速草稿（产量优先）,
  工业精工（质量交付）, 屎山抢救（存量维护）, 严格合规（审计优先）,
  交付变现（交付优先）.

## Notes

- Plans are AI-generated from the goal + interview answers + mode (0.1.29);
  the template remains only as a fallback.
- Solo plans still use quality contracts (acceptance/verify/review linkage).

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.30
# restart DSH once: host code changed
```
