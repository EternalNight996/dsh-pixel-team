# dsh-pixel-team 0.1.51

Released 2026-10-29. GitHub-only release; npm `latest` stays on 0.1.16.

## Fixed

- **Auto review in parallel DAGs**: eligibility now checks the review's own
  dependency closure instead of every quality task. A review can close while a
  sibling branch still runs; a failure outside the closure does not block it.
- Auto-review eligibility is a pure module with six regression tests.
- **Release guard** also rejects a dirty lib tree (uncommitted generated files),
  in addition to untracked files and unresolved imports.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.51
# restart DSH once: host code changed
```
