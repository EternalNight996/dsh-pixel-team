# dsh-pixel-team 0.1.84

Released 2026-10-31. GitHub-only release; npm `latest` stays on 0.1.16.

## Fixed

- **Durable oath submission**: the wizard persists an in-flight marker and,
  after a window/session switch, recovers the newly staged team from
  `/state` and opens review. If no team appears within 90s it shows a retry
  message instead of hanging on the oath screen.
- Existing-team notice is shown inline on the oath step.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.84
# restart DSH once
```
