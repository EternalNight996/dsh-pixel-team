# dsh-pixel-team 0.1.5

Released 2026-10-27.

## Profile seed quality

- Named profile seed tasks can now declare `kind` and the full quality
  contract: `objective`, `acceptance`, `inScope`, `outOfScope`, `verify`,
  `reviewedTaskId`, `sourceTaskId`, `sourceFindingIds`, `coverageOf`.
- Profile validation rejects a quality seed without its required contract and
  rejects review/repair references to unknown or self seed ids.
- Seed ids are mapped to real task ids when the team is created, so review and
  repair contracts work after creation.

## Changed-path audit

- On implementation/repair completion the host now compares the declared
  `changedPaths` with the workspace's real `git status`. A declared path that
  does not exist in the current diff rejects the completion.
- Non-git workspaces are not treated as an audit failure; the scope and evidence
  gates still apply.

## Install

```bash
dsh plugin --profile desktop add dsh-pixel-team@0.1.5
# restart DSH
```
