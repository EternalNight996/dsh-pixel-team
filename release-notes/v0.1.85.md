# dsh-pixel-team 0.1.85

Released 2026-10-31. GitHub-only release; npm `latest` stays on 0.1.16.

## Fixed

- When oath submission is rejected because this session already leads a team,
  the wizard now clears the in-flight marker and shows the replace confirmation
  inline. It no longer silently starts the 90s recovery timer and ends with
  "generation lost".

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.85
# restart DSH once
```
