# dsh-pixel-team 0.1.29

Released 2026-10-29. GitHub-only release; npm `latest` stays on 0.1.16.

## Added

- **AI-generated founding plan**: the staged DAG is derived from the goal, the
  interview answers and the mode — task titles/descriptions, roles, dependencies,
  acceptance, verify commands, scope and review linkage. The fixed template only
  applies when the model output is invalid/unavailable, so the plan is no longer
  the boilerplate "需求→实现→验证→审查" chain.
- **藏经阁 stop button**: running/claimed task cards expose ■ 停止; the host
  revokes the attempt, fails the task and blocks downstream tasks.
- **任务与架构明细** section in the library panel: id, subject, assignee, status,
  dependencies and full description per task.

## Changed

- Cost display is CNY (¥, rate 7.2) in the library header and cost dialog;
  budgets and logs remain USD.
- The destructive "结束旧宗门并开新宗" confirmation button is red.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.29
# restart DSH once: host routes changed
```
