# dsh-pixel-team 0.1.40

Released 2026-10-29. GitHub-only release; npm `latest` stays on 0.1.16.

## Fixed

- **Solo execution**: starting a task failed with "captain is busy with t2"
  because a solo plan pre-assigns every task to the captain and the captain
  busy-guard counted the queued tasks. The guard is skipped for zero-member
  teams; the captain can start each ready task in dependency order.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.40
# restart DSH once: host code changed
```
