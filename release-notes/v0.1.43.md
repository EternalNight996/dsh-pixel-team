# dsh-pixel-team 0.1.43

Released 2026-10-29. GitHub-only release; npm `latest` stays on 0.1.16.

## Fixed

- **Hall whitespace**: the scene letterboxed because the office height was capped
  at 640px while the panel could grow large. The cap is gone and the hall window
  is capped near the scene's aspect, so the canvas fills the panel.
- **Collapse control**: now an icon button (—) with tooltip/aria-label instead of
  the text "收起山门洞府".
- **Collapsed token**: the big 4/4 badge was removed so the icon stays readable.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.43
# client+host change: refresh or restart once
```
