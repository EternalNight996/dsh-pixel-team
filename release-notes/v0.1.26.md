# dsh-pixel-team 0.1.26

Released 2026-10-29. GitHub-only release; npm `latest` stays on 0.1.16.

## Fixed

- AI polish could finish without a visible change: reasoning models consumed the
  500-token budget before emitting text, so the call degraded to the original
  text silently. The budget is now 2000 tokens, and a degraded result shows the
  concrete reason under the button (e.g. "AI 未返回可用结果：…").
- The same larger budget applies to clarification options and interview
  question/answer generation.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.26
# restart DSH once: host code changed
```
