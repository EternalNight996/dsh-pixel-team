# dsh-pixel-team 0.1.67

Released 2026-10-30. GitHub-only release; npm `latest` stays on 0.1.16.

## Changed

- **DSH 0.2.1-rc.5 support**: dev dependencies and overrides moved to rc.5,
  peer ranges and `compatibility.json` include rc.5 (rc.3 stays supported).
  This fixes the plugin being marked 异常 ("incompatible with DSH 0.2.1-rc.5")
  after the host update.
- Compatibility policy test follows the new recommended host.

> Note: the official Codex/Claude subagent plugins installed at 0.2.1-rc.3 are
> also denied on rc.5; update them to 0.2.1-rc.5 separately.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.67
# restart DSH once
```
