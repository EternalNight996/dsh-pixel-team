# dsh-pixel-team 0.1.55

Released 2026-10-29. GitHub-only release; npm `latest` stays on 0.1.16.

## Changed

- **Architecture lifecycle**: `ARCHITECTURE.md` is refreshed on staged plan
  edits, regeneration and approval, not only at founding. Its product root uses
  the implementation task's inScope.
- **Captain cost visibility**: captain-executed quality tasks now write a cost
  entry with decision `captain-unmetered`; the roster ledger shows the task as
  "未计量" instead of omitting it. No fake estimate is invented.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.55
# restart DSH once: host code changed
```
