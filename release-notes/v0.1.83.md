# dsh-pixel-team 0.1.83

Released 2026-10-31. GitHub-only release; npm `latest` stays on 0.1.16.

## Changed

- Doctrine space: removed the long hint paragraph and per-card descriptions;
  cards show title + role count.
- After oath, the review sheet opens using the creation event's own session id,
  so "生成中" is followed by a review even if the current session is missing.
- Solo plans force every task assignee to captain after staging.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.83
# restart DSH once
```
