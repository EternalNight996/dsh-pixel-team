# dsh-pixel-team 0.1.12

Released 2026-10-27.

## Cleanup from the panel

- The activity panel now has a **清理旧宗门 / Clean up** button.
- It first performs the same dry run as `agent_teams_cleanup`, then asks for
  confirmation before archiving terminal teams older than 7 days.
- The current captain's team is never selected.
- The result (none / archived count / failure) is shown inline.

## Install

```bash
dsh plugin --profile desktop add dsh-pixel-team@0.1.12
# restart DSH
```
