# dsh-pixel-team 0.1.49

Released 2026-10-29. GitHub-only release; npm `latest` stays on 0.1.16.

## Added

- **`quality.reviewMode`**: `"auto"` (default) lets the host close an
  auto-audited review; `"human"` runs the same host audit but stops at
  「待人工复核」 in 藏经阁. The row shows a `确认复核` button; confirming binds the
  verdict to the audited artifact bytes and completes the review.

```yaml
quality:
  autoReview: true
  reviewMode: "human"
```

Auto review still refuses when any task failed, acceptance is missing/failed
(unless requireAcceptance is off) or host commands fail.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.49
# restart DSH once: host code changed
```
