# dsh-pixel-team 0.1.35

Released 2026-10-29. GitHub-only release; npm `latest` stays on 0.1.16.

## Changed

- **Solo captain is a single-click item** in the 宗门 step: one click clears the
  roster, hides member chips and stages a zero-member plan; clicking again
  leaves solo mode.
- **Solo teams actually execute**: on approval, a zero-member team steers the
  captain with explicit steps (status → reassign to captain → work inside
  projects/ → update → next task), so no member has to exist.
- **Boundary without a hard-coded list**: protected platform paths are derived
  from the workspace manifest (main/files/bin/tsconfig/existing roots), with
  config overrides `boundary.forbidden` and `boundary.productsDir`.
- Collapsed hall token is now an **icon** (app icon, otherwise ⛩) with a glow
  pulse and a task-count badge.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.35
# restart DSH once: host code changed
```
