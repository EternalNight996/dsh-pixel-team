# dsh-pixel-team 0.1.62

Released 2026-10-30. GitHub-only release; npm `latest` stays on 0.1.16.

## Added

- **Plan contract in review**: each staged task card now shows objective,
  acceptance criteria, verify commands and in-scope paths, so approval is not
  based on titles alone.
- **Archive old teams** in the roster history: previews every terminal team,
  archives via the host cleanup route (current captain's team excluded), then
  reloads.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.62
# restart DSH once: host code changed
```
