# dsh-pixel-team 0.1.39

Released 2026-10-29. GitHub-only release; npm `latest` stays on 0.1.16.

## Fixed

- **Solo approval**: approving a zero-member plan failed with "add at least one
  member before approving the plan". The runnable check now accepts a team with
  no members when every task is assigned to the captain, so the solo flow
  approves and wakes the captain as designed.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.39
# restart DSH once: host code changed
```
