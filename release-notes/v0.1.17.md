# dsh-pixel-team 0.1.17

Released 2026-10-29. GitHub-only release; npm `latest` intentionally stays on 0.1.16.

## Added

- **Blocking clarification root**: the founding wizard now confirms a fixed
  seven-section form (type, plain-language scale, UI, platforms, hardware
  candidates, exclusions, executable acceptance) before any DAG exists. The web
  route rejects a plan without it; `agent_teams_clarify` serves the chat path.
- **Project constitution**: a read-only `.pixel-team/<project>-constitution.json`
  is generated from the clarification and prepended to every member persona.
  Members can query the memory vault through `agent_teams_memory_recall`.
- **AI requirement polish**: optional one-shot expansion with a three-block
  preview (original / expanded / hidden conditions) before clarification; any
  model failure falls back to the original text.
- **道通藏书阁**: live DAG projection pushed over SSE — swimlanes by dependency
  depth, topology edges, acceptance PASS/FAIL, blocker bar and today's cost. No
  polling and no second state store.
- **Soft cost gate**: per-spawn estimate, per-task/day thresholds, a
  continue/terminate prompt that cancels only the current spawn, and a JSONL
  cost log.
- **Verifier acceptance**: executable constitution criteria become verify
  commands; prose criteria stay on the gate tasks; verifier output is limited to
  【PASS】/【FAIL】 + the failing log.

## Changed

- Captain tools 15 → 17, member tools 4 → 5.
- New config: `clarify.enforce`, `memory.endpoint`,
  `cost.{enabled,perTaskUsd,perDayUsd}`.

## Verification

- `pnpm typecheck`, `pnpm build`, full `pnpm verify` exit 0; git-artifact stamp
  unchanged. SSE streaming and the cost dialog still need a live smoke after a
  restart.
