# dsh-pixel-team 0.1.104

Released 2026-10-31. GitHub-only release; npm `latest` stays on 0.1.16.

## Added

- Live "恢复上次" action: re-dispatches the most recent failed/cancelled task
  through the existing `agent_teams_reassign_task` path. The action is hidden
  when no interrupted task remains, so a second click is a no-op.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.104
# restart DSH once
```
