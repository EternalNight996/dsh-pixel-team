# dsh-pixel-team 0.1.101

Released 2026-10-31. GitHub-only release; npm `latest` stays on 0.1.16.

## Fixed

- Fall back to `localStorage["dsh.sessions.current"]` when the host session list
  has no current. This gives founding a valid sessionId (no HTTP 400) and binds
  the hall to the visible conversation.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.101
# restart DSH once
```
