# dsh-pixel-team 0.1.70

Released 2026-10-30. GitHub-only release; npm `latest` stays on 0.1.16.

## Added

- **Stalled-member watchdog** (opt-in):
  ```yaml
  watchdog:
    timeoutMs: 900000   # 15 min grace, 0 disables
    intervalMs: 60000
  ```
  When an open attempt's owning member is idle or missing past the grace period,
  the task is failed with a reason, the attempt is cleared, the captain is woken
  and the team is rescheduled.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.70
# restart DSH once
```
