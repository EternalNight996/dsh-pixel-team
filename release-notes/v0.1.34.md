# dsh-pixel-team 0.1.34

Released 2026-10-29. GitHub-only release; npm `latest` stays on 0.1.16.

## Added

- **Founding project boundary**: every generated project lives under
  `projects/<slug>/`. The plan generator's `inScope` must stay inside that root;
  platform paths (`src/`, `lib/`, `scripts/`, `assets/`, `docs/`,
  `package.json`, `tsconfig*`, `cordis.patch.yml`, ...) are rejected. Missing
  implementation scopes are filled with the root, and the template fallback is
  confined to it as well.
- New tests `scripts/project-boundary.test.mjs` (root/slug, traversal,
  platform paths, spec rejection/filling, fallback confinement).

## Notes

- A 试炼场 (trial ground) preview is analyzed separately; it is not part of this
  release.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.34

```
