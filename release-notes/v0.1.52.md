# dsh-pixel-team 0.1.52

Released 2026-10-29. GitHub-only release; npm `latest` stays on 0.1.16.

## Added

- **Regenerate plan**: the staged review can discard the current draft and
  re-stage from the stored goal, clarification and roles.
- **Requirement coverage**: requirement items are mapped to gate tasks; the
  library table now shows per-item PASS/FAIL and per-item failure counts.
- **Human review notification**: when a review waits for confirmation, the
  captain receives a mailbox notice.
- **Product verify auto-detection**: with `quality.autoDetect` (default true),
  host verification adds the generated project's own `package.json`
  test/typecheck command (`cd <root> && <manager> run <script>`).

## Tests

- New coverage/product-verify regression tests; web contracts 120+.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.52
# restart DSH once: host code changed
```
