# dsh-pixel-team 0.1.69

Released 2026-10-30. GitHub-only release; npm `latest` stays on 0.1.16.

## Added

- **Task-level skills**: the plan task editor loads the host skill catalog and
  supports multi-select. Selected skills persist on the task, appear in the
  review contract, and the assignment tells the assignee to load them with the
  host `skill` tool before working.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.69
# restart DSH once
```
