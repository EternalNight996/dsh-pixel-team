# dsh-pixel-team 0.1.59

Released 2026-10-29. GitHub-only release; npm `latest` stays on 0.1.16.

## Fixed

- **Roster cost still ¥0**: the hall overlay can be mounted without a session
  prop, so the cost report was never requested. It now falls back to the team's
  captain session id.
- The ledger header shows the selected team total and auto-refreshes every 15s.

Client-only change; no host restart is required (refresh the page).

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.59
```
