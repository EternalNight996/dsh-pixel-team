# dsh-pixel-team 0.1.9

Released 2026-10-27.

## Delivery report export

- The activity panel shows a **交付报告 / Delivery report** button when
  `delivery.ok` is true.
- The button downloads `delivery-report-<team>.md` from the snapshot's
  verified report: goal, quality/work tasks, acceptance evidence, changed
  paths, host-verified commands, review verdicts, residual risks.
- No extra host route or browser permission is needed; the report is part of
  the same authenticated activity snapshot.

## Cleanup

- Includes the 0.1.8 `agent_teams_cleanup` tool for abandoned terminal teams.

## Install

```bash
dsh plugin --profile desktop add dsh-pixel-team@0.1.9
# restart DSH
```
