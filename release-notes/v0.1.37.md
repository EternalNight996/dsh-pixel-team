# dsh-pixel-team 0.1.37

Released 2026-10-29. GitHub-only release; npm `latest` stays on 0.1.16.

## Changed

- **Shorter founding wait**: the wizard no longer makes a separate AI call to turn
  interview answers into a clarification. Answers are folded into the
  clarification as constraints locally, and the plan generator now receives them
  explicitly ("用户访谈约束"), so founding costs one model round instead of two.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.37
# client+host change: refresh or restart once
```
