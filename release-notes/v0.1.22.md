# dsh-pixel-team 0.1.22

Released 2026-10-29. GitHub-only release; npm `latest` stays on 0.1.16.

## Added

- **Five development modes**: ⚡ 极速草稿, 🏭 工业精工, 🔧 屎山抢救,
  🛡️ 严格合规, 💰 交付变现. One table (src/modes.ts) defines each mode's
  philosophy, default boundaries, acceptance baseline, verifier strategy,
  failure limit and cost budget.
- The founding wizard has a mode selector. Requirement polish and the AI
  clarification options are generated for that mode, and the mode is stored on
  the clarification and in the project constitution.
- Every member persona begins with the mode philosophy block, so spawn and cold
  resume share the same execution stance.
- Clarification defaults are mode-shaped: e.g. 屎山 adds 禁止重构底层/禁止修改原有
  接口协议/禁止删除旧测试; 合规 adds 禁止访问公网/禁止打印明文密码/禁止引入未审核
  第三方包, and their acceptance baselines.

## Changed

- Legacy clarifications/constitutions without a mode default to precision.
- AI options parsing always injects the mode's mandatory boundaries/acceptance.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.22
# restart DSH once: this release changes host code (mode plumbing)
```
