# dsh-pixel-team 0.1.32

Released 2026-10-29. GitHub-only release; npm `latest` stays on 0.1.16.

## Changed

- Renamed the panel to **道统·藏经阁** (previously 道通藏书阁).
- Task progress is now a **single-column list**: each row shows id, subject,
  assignee, status and acceptance count; clicking a row expands its description,
  dependencies and kind. Live SSE updates and the ■ 停止 button are unchanged.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.32
# restart DSH once: the stop-task output text changed in host code
```
