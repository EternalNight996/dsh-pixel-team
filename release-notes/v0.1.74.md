# dsh-pixel-team 0.1.74

Released 2026-10-30. GitHub-only release; npm `latest` stays on 0.1.16.

## Changed

- **Watchdog on by default**: 15-minute grace, 60s scan. An idle/missing member
  owning an open task is marked failed with a reason, the attempt is cleared, the
  captain is woken and the team is rescheduled. Running owners are never timed
  out. Set `watchdog.timeoutMs: 0` to disable.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.74
# restart DSH once
```
