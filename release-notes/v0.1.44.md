# dsh-pixel-team 0.1.44

Released 2026-10-29. GitHub-only release; npm `latest` stays on 0.1.16.

## Added

- **Core architecture**: from the confirmed requirement + DAG the plugin builds a
  deterministic architecture document (goal, stack/platform, constraints,
  non-goals, acceptance, module skeleton, product root), writes it to
  `projects/<root>/ARCHITECTURE.md` at founding, shows it in 藏经阁 and injects
  it into every member persona so later turns do not lose context.

## Changed

- 名册 dropdown has state colors (🟢/🔴/🟡/🔵) and a matching border.
- 藏经阁 requirement checklist is a table with #, requirement, state and failure
  count, plus a failure total; task subjects wrap instead of truncating.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.44
# restart DSH once: host code changed
```
