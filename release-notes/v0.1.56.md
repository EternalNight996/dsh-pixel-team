# dsh-pixel-team 0.1.56

Released 2026-10-29. GitHub-only release; npm `latest` stays on 0.1.16.

## Fixed

- **Cross-team cost leakage in 藏经阁**: the per-task cost query did not pass the
  current team id, so task ids were aggregated across every team and a new team
  could display another team's spend. It now passes `teamId`.

Found by the full business-flow browser E2E (开宗 → AI 计划 → 批准 → 单掌门执行
→ 4/4 完成 → review pass → delivery.ok=true, 3 host-verified commands).

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.56
# restart DSH once: host code changed
```
