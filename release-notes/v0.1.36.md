# dsh-pixel-team 0.1.36

Released 2026-10-29. GitHub-only release; npm `latest` stays on 0.1.16.

## Fixed

- **Solo founding error**: create_task rejected `assignee: "captain"` with
  "no active member named captain". The captain is now accepted as a task owner,
  so a zero-member solo plan stages correctly.
- **Founding feedback**: the wizard shows a pulsing note while the AI plan is
  generated (usually 10-60s), and it hands over to the plan review as soon as the
  team is staged (delay reduced from 1.4s to 0.3s), instead of sitting on the
  pre-founding view.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.36
# restart DSH once: host code changed
```
