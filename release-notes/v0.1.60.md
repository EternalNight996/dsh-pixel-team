# dsh-pixel-team 0.1.60

Released 2026-10-29. GitHub-only release; npm `latest` stays on 0.1.16.

## Changed

- **Roster dropdown cost sync**: option totals refresh every 15s, matching the
  bottom cost ledger instead of staying at the value from first mount.
- **Package slimmed**: packed size 6.95 MB -> **1.42 MB**, files 378 -> 309.
  Marketing-only `assets/app-icons` (4.1 MB) and `assets/readme` (1.5 MB) are no
  longer shipped; they remain in the repository. The client's app icon is
  embedded in `art-data.ts`, so runtime UI is unchanged.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.60
# restart DSH once: host code changed
```
