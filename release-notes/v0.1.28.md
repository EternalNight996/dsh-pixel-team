# dsh-pixel-team 0.1.28

Released 2026-10-29. GitHub-only release; npm `latest` stays on 0.1.16.

## Changed

- The existing-sect confirmation is a floating tag (标签式浮船) anchored above the
  submit button with a tail pointing at it, instead of an inline block.
- While AI polish is running, 下一步 / step dots are disabled and the goal
  textarea is read-only, so the polished result cannot race manual edits.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.28
# client-only change: refresh the page after install
```
