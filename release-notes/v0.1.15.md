# dsh-pixel-team 0.1.15

Released 2026-10-28.

## Hardening

- The 「立誓开宗」 staging path now lives in a tested helper: the roster is
  created first, then every task is added through `agent_teams_create_task`
  with its quality contract, and a failure rolls the half-staged team back.
- New mocked tests cover creation order, dependency/review id mapping, rollback
  after a failed task, a failed create, and missing tools.

## Fixed

- A breakthrough (1200ms) cast no longer freezes on the first frame for 250ms;
  the frame index follows the real cast window. The 950ms equipment cast is
  unchanged.

## Install

```bash
dsh plugin --profile desktop add dsh-pixel-team@0.1.15
# restart DSH
```
