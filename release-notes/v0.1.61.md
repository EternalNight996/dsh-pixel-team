# dsh-pixel-team 0.1.61

Released 2026-10-30. GitHub-only release; npm `latest` stays on 0.1.16.

## Changed

- **Plan generation retry**: when the first AI plan fails host validation or is
  unrelated to the goal, one stricter retry runs (lower temperature, explicit
  contract reminder). Timeouts/aborts do not retry. A second failure still falls
  back to the template plan and records the reason.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.61
# restart DSH once: host code changed
```
