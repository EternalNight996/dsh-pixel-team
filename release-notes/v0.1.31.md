# dsh-pixel-team 0.1.31

Released 2026-10-29. GitHub-only release; npm `latest` stays on 0.1.16.

## Added

- **🐍 贪吃蛇大作战** panel in the hall: a 320×320 Canvas game mounted as a hall
  sheet with a bottom entry, keyboard arrows + on-screen four-way pad, pause /
  restart (Space or buttons), +10 per food, wall/self collision ends the game,
  and full timer/keyboard cleanup on close.
- Regression tests `scripts/snake-game.test.mjs` wired into `verify:web-routes`.

## Fixed

- Same-tick 180° double turn no longer kills the snake instantly (committed-
  direction check + stepGame guard).
- The panel keyboard no longer intercepts arrows/Space while an input or
  contenteditable element is focused.
- The virtual pad moved out of the board, so it no longer covers the bottom-right
  cells.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.31
# restart DSH once: host bundle changed
```
