# dsh-pixel-team 0.1.13

Released 2026-10-27.

## The hall actually moves now

- Every cultivator is drawn from a cached frame sheet — sitting, walking, riding
  and a four-frame cast. One `drawImage` per figure per frame replaces a few
  hundred per-frame `fillRect` calls.
- Breaking through, swapping a mount or equipping an artifact plays the cast
  animation with a burst of sparks.
- Mounts animate a real four-frame gait: legs and hooves swing.
- Skill sigils float beside equipped cultivators instead of being painted inline
  with the rest of the figure.

## Fixed

- A hopping mount stayed on the ground while its rider jumped; the mount now
  lifts with the rider.
- Quadruped mounts used to repeat the same two frames (four-frame gait had only
  two unique poses); all four frames now differ.

## Tests

- New Node canvas-stub suite pins the frame sheets: pose counts, cache reuse,
  1px ink outlines, per-role palettes and gait uniqueness — no native image
  dependency, wired into `pnpm verify:web-routes`.

## Install

```bash
dsh plugin --profile desktop add dsh-pixel-team@0.1.13
# restart DSH
```
