# dsh-pixel-team 0.1.68

Released 2026-10-30. GitHub-only release; npm `latest` stays on 0.1.16.

## Added

- **Autonomy contract** for captains and members: decide inside the approved
  goal/inScope/acceptance/verify, record assumptions, and ask only about
  irreversible, out-of-scope, credential-bound, or goal-changing decisions.
- **Host Goal visibility**: the snapshot and plan review show the captain's
  active goal; the captain protocol defers autonomous continuation to the host
  Goal Round Driver instead of creating a duplicate goal.

## Install (GitHub)

```bash
dsh plugin --profile desktop add github:EternalNight996/dsh-pixel-team#v0.1.68
# restart DSH once
```
