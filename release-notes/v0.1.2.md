# dsh-pixel-team 0.1.2

Released 2026-10-27.

## Fixes

- **Stop button is red** — the destructive stop icon now uses the danger color instead of gray.
- **Stop confirmation is an anchored popover** — it sits next to the stop button, above the progress
  panel, instead of a centered modal that could be covered. Esc / click-outside closes it; focus
  starts on cancel.
- **"结束旧宗门并开新宗" is a red destructive action** — the existing-sect prompt now points to it.
  After the user explicitly confirms, the host ends the current team even with live work and founds
  the new sect.
- Updated the existing-sect copy so it no longer points at an invisible "Teams" pane.

## Install

```bash
dsh plugin --profile desktop add dsh-pixel-team@0.1.2
# reopen DSH → 山门 · 名册
```
