# dsh-pixel-team 0.1.14

Released 2026-10-28.

## Fixed

- 「立誓开宗」/ quick-start no longer fails with `plan.tasks[0].kind is not a
  declared property`. The create tool's plan only accepts ordinary task fields,
  so the wizard now stages the roster first and adds every task — with its
  quality contract — through `agent_teams_create_task`.
- If a task fails midway, the half-staged team is rolled back instead of
  blocking the next attempt with "already lead team".

## Tests

- New quick-start staging suite: dependency order, quality contracts through
  create_task, and no undeclared create-plan fields; wired into
  `pnpm verify:web-routes`.

## Install

```bash
dsh plugin --profile desktop add dsh-pixel-team@0.1.14
# restart DSH
```
